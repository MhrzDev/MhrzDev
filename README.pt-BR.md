## Projetos em Destaque

### ServiceDesk Platform

Plataforma full stack de gerenciamento de chamados, com autenticação, controle de acesso por função, conversas, anexos privados, relatórios e interface bilíngue.

**Tecnologias:** React, TypeScript, Supabase e PostgreSQL.

[Ver repositório](https://github.com/MhrzDev/servicedesk-platform)

---

### StockFlow API

API REST segura para gerenciamento de estoque, com autenticação JWT, permissões por função, movimentações transacionais, documentação OpenAPI e testes automatizados.

**Tecnologias:** Node.js, TypeScript, Express, PostgreSQL, Docker e Vitest.

[Ver repositório](https://github.com/MhrzDev/stockflow-api)

---

### Central de Comando Policial

Plataforma de gerenciamento para departamentos policiais em ambientes FiveM RP, com autenticação, permissões por função, gestão de efetivo, operações, treinamentos, controle de serviço e fluxos administrativos.

**Tecnologias:** JavaScript, Node.js, Express, PostgreSQL e Supabase.

[Ver repositório](https://github.com/MhrzDev/police-command-center)

---

### Sistema de Gestão de Unidade Tática

Sistema de gerenciamento operacional desenvolvido para organizar membros, atividades e processos internos.

Inclui registros de atividades, controle de presença, horas e pontos, requisitos de promoção, cursos, solicitações, notificações e painéis administrativos.

**Tecnologias:** JavaScript, Node.js, PostgreSQL e Supabase.

[Ver repositório](https://github.com/MhrzDev/tactical-unit-manager)
